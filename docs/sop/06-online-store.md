# 6. Online store (customer side)

[← SOP index](README.md)

The store is at **`/shop`**. It is separate from the staff portal: customers have their
own accounts, and a staff login does not work on the store (or the other way round).
Staff can open it with **"View store"** in the top bar. Use this guide to help customers
on the phone.

## 6.1 Browsing and the delivery PIN code

1. On the home page, enter the site's PIN code in **"Where should we deliver?"** →
   **"Check"** (or **"Deliver to"** in the header). It is remembered on that device.
2. Browse **categories** (left), **brands**, or **search** ("Search cement, TMT bars,
   blocks, tiles…").

**The PIN code decides stock and delivery, not price.** Each product shows a badge:

| Badge | Meaning |
| --- | --- |
| **Check delivery** | No PIN code entered yet |
| **In stock** | Warehouses serving this PIN have it |
| **Out of stock** | This PIN is served, but none is available now |
| **Not delivered to your PIN code** | No warehouse serves this PIN yet |

**Each order is delivered in one go from one place.** So the quantity shown is the most
one order can have, and the date is when it can arrive.

The product page shows, per size: price **excluding GST** (e.g. "₹400.00 per BAG · excl.
28% GST"), bulk rates ("₹380.00 per BAG when you buy 100+ BAG"), the quantity available
and **"Delivery by …"**. "Price on request — call us for a quote" means the item has no
price or no GST rate yet.

## 6.2 Account

- **"Create an account"** — full name, email, password (8+), mobile (optional, with country
  code), company (optional). If the email is already in use the store says "We could not
  create an account with these details. If you already have an account, sign in instead."
  — it never reveals whether an email exists.
- **"Sign in"** — wrong details or a blocked account: "That email and password do not match
  a store account."
- **"My details"** — name, mobile, company, GSTIN and a default delivery address.
- There is no self-service password reset yet; staff cannot see or reset passwords either.

## 6.3 Cart

1. On a product, choose quantity and unit → **"Add to cart"** (signing in if asked; the
   item is added after sign-in).
2. In **"Your cart"**, change quantity or unit and **"Update"**, or remove a line. Price per
   line follows the bulk slab for that quantity.
3. The summary shows items excluding GST, **CGST + SGST** or **IGST**, cess and **"Total
   payable"**, plus "Delivery by …".
4. **"Proceed to checkout"** is disabled while any line has a problem, for example:
   - "Only 40 BAG can be delivered to PIN code 411001 right now." → reduce the quantity.
   - "These items cannot all be delivered together to PIN code … right now." → every item
     is available, but not all from one place. Lower a quantity or remove an item and order
     it separately (each order is delivered in one go).
   - "Not delivered to PIN code …" / "Out of stock for PIN code …" → remove it or try
     another PIN.
   - "This item cannot be ordered online yet. Please contact us for a quote."
   - "This item is no longer sold. Remove it to continue."

A cart holds up to 50 items.

## 6.4 Checkout

1. **Delivery address** — the PIN decides availability and the **state decides GST**.
2. **Contact** — **mobile number is required** ("We call this number to confirm the order
   and delivery slot."); GSTIN optional for a business invoice; tick "Save this address and
   number for next time".
3. **Payment** — nothing is paid online. "Your stock is held as soon as you place the
   order; we confirm it with you by phone, and you pay in cash when it is delivered."
4. **"Place order"** → "Thank you — your order is placed", with the order number.

If someone else buys the last stock at the same moment: "…someone has just ordered the
last of it… Your cart is kept — please update it and try again." Pressing "Place order"
twice never creates two orders.

## 6.5 My orders

**"My orders"** lists each order with its status: **Order placed**, **Confirmed** (the
store has called and agreed it; pay in cash on delivery), **Cancelled**, or **Closed**
(not confirmed in time). While an order is only placed the customer can cancel it under
**"Changed your mind?"**; once confirmed they must call the store to change or cancel it.

## 6.6 What customers never see

Warehouse names, codes, addresses or which warehouse supplies them. They see one
available quantity, the price, GST and a delivery date. Staff must not tell customers
which warehouse holds their order.
